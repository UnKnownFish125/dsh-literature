# dsh-literature 模型 v0.3 —— 完整知识库与归档体系

> 版本：model-v0.3 · 2026-09-02 · 依据：用户多轮裁决（本文档整合全部）
> 定位修正：dsh-literature（**不是 literatum**）不是"文献管理库"，也不是"deepmemory 查询代理"——
> 它是 **完整的知识库 + 归档体系**：管理原料→归档→加工→知识的全生命周期，
> 与 deepmemory 建立**专属对接**（deepmemory 是原料来源之一，literature 是知识的组织者）。

---

## 0. 一句话

dsh-literature 是面向 agent 与科研的**知识库与归档中枢**：文献/对话/文档等原料先归档（原文保存、可溯源），
夜间用低成本模型批量加工成结构化知识，知识挂载到可配置深度的多级分类树（工作区隔离 + 跨区共享 + 权限），
每条知识可多标签（科研领域重叠），挂载点可溯源回原始归档。

## 2. 分层架构

```
┌────────────────────── dsh-literature（6260 演进为单服务）──────────────────────┐
│                                                                               │
│  ┌─ 原料层（收）────────────────────────────────────────────────────────┐     │
│  │  · 文献/网页/手动文档（上传/导入：BibTeX/PDF/DOI）                     │     │
│  │  · deepmemory 专属对接（记忆归档带原始对话 → 作为原料归档）            │     │
│  └───────────────────────────────────────────────────────────────────────┘     │
│                          ▼                                                   │
│  ┌─ 归档层（存原文）────────────────────────────────────────────────────┐     │
│  │  · 原文全文 + 元数据（位置可配置 `archive.dir`）                      │     │
│  │  · 不向量化，BM25/全文检索即可（裁决 16）                            │     │
│  │  · 溯源锚点：每条归档有稳定 id，供知识挂载引用                        │     │
│  └───────────────────────────────────────────────────────────────────────┘     │
│                          ▼                                                   │
│  ┌─ 缓存区（待加工）────────────────────────────────────────────────────┐     │
│  │  · 新知识/新原料先进缓存（裁决 8），不直接入知识库                    │     │
│  └───────────────────────────────────────────────────────────────────────┘     │
│                          ▼ 夜间管线（低谷时段，裁决 5/6）                     │
│  ┌─ 加工层（夜间批量）──────────────────────────────────────────────────┐     │
│  │  · 默认模型 uuapi/v4-flash-0731（便宜），配置可暴露                   │     │
│  │  · 输入三渠道：自动(缓存) / agent 提交 / 手动输入                     │     │
│  │  · 产出：结构化知识条目（提炼，非原文）+ 主挂载判定                    │     │
│  └───────────────────────────────────────────────────────────────────────┘     │
│                          ▼                                                   │
│  ┌─ 知识库（成品，存知识）──────────────────────────────────────────────┐     │
│  │  · 知识条目（加工产物）→ 向量化（bge-m3，裁决 17）                    │     │
│  │  · 挂载：多级分类树 + primary/secondary 多标签（裁决 11-15）           │     │
│  │  · 挂载点引用归档 id → 可溯源（裁决 9/10）                            │     │
│  └───────────────────────────────────────────────────────────────────────┘     │
│                                                                               │
│  面向 agent：kb_query / kb_browse / kb_constraints / kb_contracts / 申请分类    │
└───────────────────────────────────────────────────────────────────────────────┘
                          ▲ 查询/申请
        ┌─────────────────┴──────────────────┐
        ▼                                    ▼
  deepmemory（记忆层）                    DSH Agent
  · 记忆存取（无库概念，裁决 3）           · 调度/查询/申请派生
  · 归档带原始对话（契约修订后）
```

## 3. deepmemory 专属对接（任务 3 契约修订）

**原则**：deepmemory 只做记忆存取；literature 是知识组织者。

```
deepmemory 侧（契约修订点）：
  · 归档导出（memory_archives/归档 API）→ 增加"含原始对话全文"的导出形态
  · 向 literature 发起查询（kb 请求）与申请（建分类/归类/归档回流）

literature 侧（对接模块）：
  · 拉取 deepmemory 记忆归档（带原始对话）→ 存入本库归档层（原料）
  · 接受 deepmemory/agent 的知识查询 → 走本库知识检索
  · 接受分类申请 → 本库分类树管理后反馈
```

## 4. 分类树（动态、可配置深度、工作区隔离 + 共享）

```
全局：bias 树（一份，跨工作区共享，裁决 15）

每工作区一棵树（裁决 13）：
workspace:deepseek-harness
├── daily            （默认 seed）
├── workspace        （默认 seed = 工作区知识）
│   ├── L2 子类 …    （agent 申请派生）
│   │    └── L3 …    （深度可配置，默认 3，配置 category.max_depth）
├── core / eco       （预置，空占位不占空间，裁决 4 前轮）
```

**权限**（owner/contributor/viewer）：
| 角色 | 建树/删树 | 申请派生 | 标注/挂载 | 跨区只读 |
|---|---|---|---|---|
| owner | ✅ | ✅ | ✅ | — |
| contributor | — | ✅ | ✅ | — |
| viewer | — | — | — | ✅ |

**跨工作区共享**：子树授权（如 workspace-A 的 `科研/认知科学` 子树共享给 workspace-B 只读）。

## 5. 挂载与溯源

| 概念 | 规则 |
|---|---|
| primary 挂载 | 每条知识必有且仅 1 个主挂载点（决定归属/统计） |
| secondary 挂载 | 0..n 个，跨类/领域重叠（科研核心） |
| bias 自动跨挂 | 行为约束类知识即使 primary 在别处，强制补挂全局 bias 节点 |
| 挂载点 = 源点 | 每个挂载点引用 `archive_id`，可溯源到原始归档全文 |
| 溯源链 | 知识 → 挂载点 → archive_id → 归档原文（含原始对话/文献全文） |

## 6. 知识向量（裁决 16/17）

- **归档原文：不向量化**（BM25/全文检索）
- **知识条目：向量化**（加工成品才向量）
- 默认模型：`http://127.0.0.1:6192` bge-m3（1024 维，ctx 8192）
- 可配置切换：qwen3-embedding-0.6B（`http://127.0.0.1:6193`，1024 维）
- 索引：FAISS（沿用 deepmemory 架构经验）

```json
"embedding": {
  "provider": "api",
  "api_base_url": "http://127.0.0.1:6192",
  "api_model": "bge-m3",
  "dim": 1024,
  "fallback_base_url": "http://127.0.0.1:6193",
  "fallback_model": "Qwen3-Embedding-0.6B"
}
```
